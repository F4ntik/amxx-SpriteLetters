# SpriteLetters 1.4.2-bones-dev

Локальный кандидат от 8 октября 2026: объёмная рамка и фон теперь занимают один игровой объект. Для размера 256 × 64 в прежней 1.4.1 требовалось 35 деталей; буквы по-прежнему имеют собственные объекты.

## Что изменено

- Оформление 3 использует одну заранее подготовленную MDL с четырьмя костями. Два параметра управляют шириной и высотой. Окантовка остаётся шириной 4, общая толщина — 3 игровых единицы.
- Ширина 32–512, высота 16–128, шаг 4. Центр рамки остаётся относительно надписи на прежнем месте.
- Наклон MDL согласован с направлением слова: учтена инверсия pitch внутри StudioModelRenderer.
- При повороте и изменении размера обновляется ограничивающая коробка объекта для серверного расчёта видимости.
- При переходе со спрайтов лишние секции удаляются. При переходе обратно сначала выделяются недостающие объекты; при отказе текущая рамка сохраняется.
- Три спрайтовых оформления сохранены. Лимит 32 рамки и запас 64 свободных объектов карты оставлены прежними.

Новая модель: models/SprLett/frame_bones_v1.mdl (7388 байт). Прежние четыре panel_*.mdl больше не используются этой версией. Они не перезаписываются и не удаляются у игроков. Спрайты и карты символов побайтно совпадают с 1.4.1.

## Установка на тестовый стенд

1. Сделайте копию addons/amxmodx/configs/plugins/SpriteLetters/Saves.
2. Скопируйте addons, sprites и models из архива в cstrike стенда. Плагины ставятся комплектом: SprLetters.amxx → SprLett-Saver.amxx → SprLett-Editor.amxx → SprLett-Gradient.amxx. Уберите дубли старых версий из списка загрузки.
3. При использовании FastDL добавьте туда models/SprLett/frame_bones_v1.mdl по тому же пути. Перезагрузите карту для регистрации ресурса.
4. Выберите надпись, поставьте её командой slplace. В меню рамки выберите «Объёмная MDL: 1 объект» или задайте slpanel 256 64 3. Сохранение — slsave.

Совместимость окружения: AMX Mod X с JSON API, ReAPI/Fakemeta. Компиляция выполнена AMXX 1.10.0.5461; совместимость с другими версиями не проверялась.

## Сохранения

Остались прежние PanelWidth, PanelHeight и PanelStyle. Значение 3 теперь отображается одной моделью. Saver и проверка входного JSON побайтно совпадают с 1.4.1-mdl-dev; преобразование сохранений между 1.4.1 и 1.4.2 не требуется. Старые записи без рамки и стили 0–2 продолжают использоваться.

Для возврата к 1.4.0-dev сначала восстановите резервную копию либо переключите все MDL-рамки в спрайтовое оформление и явно сохраните в новой версии: 1.4.0 не принимает PanelStyle=3. Не смешивайте плагины разных сборок.

## Выполненные проверки

- Четыре AMXX собраны без ошибок и предупреждений.
- MDL скомпилирована; из бинарного файла прочитаны кости, контроллеры, вершины и границы последовательности.
- Проверены все 3509 допустимых размеров: габариты, постоянная ширина кромки и попадание в границы последовательности.
- 90 проверок геометрии при разных размерах/углах: центрирование и коробка видимости.
- Сверено, что код сохранения/валидации и общие спрайтовые ресурсы не менялись.
- Полнота архива, CRC и SHA-256 каждого вложенного файла проверены при упаковке.

Эти проверки не запускают Pawn в игровом сервере и не заменяют проверку клиента. На действующем сервере ничего не установлено. Переключение оформления и save/reload проверены только чтением кода; их игровое выполнение не подтверждено.

## Что проверить в игре

- [ ] Стена, пол, потолок и наклон; рамка совпадает с плоскостью текста.
- [ ] Размеры 32 × 16, 256 × 64, 512 × 128 и промежуточные; кромка не растягивается в толщину, надпись остаётся по центру.
- [ ] Рамка не пропадает у края экрана, при входе в комнату и после изменения размера.
- [ ] Переключение спрайт → MDL → спрайт, удаление рамки, многократное перемещение; число объектов стабильно.
- [ ] slsave → смена карты → возврат: размер, положение, текст и оформление восстановлены.
- [ ] Повторный вход клиента с ресурсами старой версии: скачивается новая модель.

Уменьшение числа объектов обеспечивается конструкцией. Прирост FPS и снижение сетевого трафика не измерялись.

## Исходники

source/SpriteLetters содержит текущие исходники и модель. tools/build_frame.py генерирует SMD/QC и текстуры из стандартной библиотеки Python; затем из model-source запустите StudioMDL с frame.qc. Результат попадёт в assets/models/SprLett/frame_bones_v1.mdl. Проверка: python tools/build_frame.py --check из source/SpriteLetters.

Состояние MDL при работе: sequence=0, frame=0, framerate=0. Второй кадр последовательности нужен компилятору только для максимальных границ, он не проигрывается. controller[0]=(width-32)/4; controller[1]=(height-16)/4. Подробности компилятора — docs/compiler-provenance.md. Журналы и ведомость сборки — outputs; все файлы перечислены в MANIFEST.sha256.

Это описание рамки из 1.4.2; в 1.4.3 также добавлены игровые значки (GAMING.md). Полный перенос на Metamod не выполнялся; вывод исследования — сначала уменьшать число объектов и измерять нагрузку, а при доказанном узком месте выносить его в нативный модуль.
