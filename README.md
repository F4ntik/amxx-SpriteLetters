# SpriteLetters 1.4.3-gaming-dev

Редактор надписей и рамок для Counter-Strike 1.6: обычный текст, бегущая строка, три спрайтовых оформления, объёмная рамка на костях и десять цветных игровых значков.

**Кандидат для проверки в игре.** Четыре плагина скомпилированы AMXX 1.10.0.5461 без предупреждений; модели, спрайты и архив проверены локально. Запуск в клиенте/сервере CS 1.6 ещё не выполнен.

[Скачать готовый комплект 1.4.3](https://github.com/F4ntik/amxx-SpriteLetters/raw/refs/heads/main/dist/SpriteLetters-1.4.3-gaming-dev.zip) · [Игровые значки](docs/GAMING.md) · [Рамка на костях](docs/FRAME.md)

## Установка

1. Сохраните резервную копию addons/amxmodx/configs/plugins/SpriteLetters/Saves и прежних плагинов.
2. Из готового ZIP скопируйте addons, sprites и models в cstrike. Требуются AMX Mod X с JSON API, ReAPI и Fakemeta.
3. Обновите плагины комплектом, в порядке: SprLetters.amxx → SprLett-Saver.amxx → SprLett-Editor.amxx → SprLett-Gradient.amxx. Gradient — необязательный демонстрационный эффект. В архиве есть configs/plugins-SprLett.ini; уберите дубли этих плагинов из других списков загрузки.
4. При использовании FastDL скопируйте новые ресурсы с теми же путями: models/SprLett/frame_bones_v1.mdl, sprites/SprLett/panel.spr и sprites/SprLett/Charsets/Gaming_v1/chars.spr. Map.txt нужен серверу.
5. Смените карту. Старые Default/Test и ранее выпущенные модели не перезаписываются под прежними именами; новые файлы получают отдельные пути.

## Быстрая проверка

Откройте консоль администратора:

```text
slcreate :ct: READY :aim: :bomb: :tt:
slplace
slpanel 256 64 3
slsave
```

slplace ставит выбранную табличку на поверхность под прицелом. slmainmenu открывает редактор. slemoji позволяет дописать значок через меню; коды работают и внутри обычного текста. Для редактирования требуется ADMIN_RCON.

| Команда | Действие |
|---|---|
| slmainmenu | Главное меню |
| slcreate текст | Создать и выбрать надпись |
| slselect | Выбрать надпись под прицелом |
| slwrite текст | Заменить текст |
| slemoji | Добавить игровой значок |
| slplace | Поставить на поверхность |
| slpanel ширина высота стиль | Рамка: стили 0–2 спрайтовые, 3 — MDL |
| slsave | Сохранить выбранную табличку |
| slremove | Удалить выбранную табличку и её сохранение |
| sl_marquee_text ID текст | Серверная команда: изменить строки с этим ID |
| sl_marquee_width ID ширина | Серверная команда: число видимых символов |
| sl_marquee_speed ID скорость | Серверная команда: скорость, 0 — пауза |

## Что изменено относительно 1.3.1

- Буквы и рамка редактируются вместе: размещение, движение, вращение, размер, оформление и сохранение. Главное меню показывает, сохранены ли изменения.
- Повторная сборка переиспользует буквы; перед расширением проверяется запас объектов. При нехватке памяти для объектов прежняя надпись остаётся на месте.
- Проверяются сохранения целиком, типы и диапазоны значений; запись выполняется через временный файл с проверкой и резервной копией. Повреждённые/незавершённые сохранения защищены от перезаписи. Сообщение об успехе выдаётся после записи.
- Рамка MDL с фоном занимает один объект; в составной версии 1.4.1 при 256 × 64 требовалось 35. Буквы имеют собственные объекты. Размер 32–512 × 16–128 с шагом 4, толщина кромки остаётся постоянной.
- Десять игровых значков смешиваются с буквами любого установленного шрифта, сохраняя свою палитру. Новый Gaming_v1 содержит 157 прежних символов и 10 новых; код ввода и меню описаны в GAMING.md.

## Сохранения и возврат

Saves/<map>.json хранит снимок последнего явного slsave. После редактирования сохраняйте заново; смена карты сама по себе последние изменения не записывает.

После незавершённой записи сохраните копии .json/.tmp/.bak, выберите корректный JSON и уберите разобранные остаточные файлы из рабочего каталога, затем смените карту. Во время работы не заменяйте файл вручную: Saver защищает внешние изменения от перезаписи.

Схема PanelWidth/PanelHeight/PanelStyle совместима с 1.4.1/1.4.2, emoji хранятся в тексте UTF-8. Для возврата к 1.4.0 восстановите резервную копию или сначала переведите все рамки в спрайтовый стиль и сохраните: 1.4.0 не принимает PanelStyle=3. Старые плагины не отрисуют новые emoji автоматически.

Составная MDL сохранена в ветке [experiment/modular-frame-v1.4.1](https://github.com/F4ntik/amxx-SpriteLetters/tree/experiment/modular-frame-v1.4.1). Её можно проверить отдельно, если вариант на костях не подойдёт. Не смешивайте Core/Editor/Saver разных сборок.

## Исходники и проверки

- amxmodx/scripting — исходники четырёх плагинов; assets — игровые ресурсы; model-source — SMD/QC для StudioMDL.
- tools/build_frame.py --check проверяет бинарную MDL: все 3509 размеров и 90 случаев ориентации/центрирования. Генерация исходников модели — запуск без --check, затем StudioMDL из model-source с frame.qc.
- tools/build_gaming.py создаёт собственные значки и Gaming_v1; tools/check_gaming.py проверяет спрайт, карту, Unicode и таблицу кодов. Для этих двух инструментов нужен Pillow.
- tools/package.py --build-dir <каталог сборки> --output <архив.zip> --previous <прежний архив.zip> упаковывает четыре бинарника, сверяет ведомость сборки, общие ресурсы, CRC и SHA-256. Входной build-receipt.json должен содержать хеши SMA/AMXX.
- Legacy build.bat сохраняется; перед запуском настройте AMXX_COMPILER_DIR и AMXX_COMPILER_EXECUTABLE=amxxpc.exe. Компилятор и local.build-config в Git не включаются.

В игре остаётся проверить длительное перемещение рамки, стены/пол/потолок, край экрана, смену оформления, save/reload и вход клиента со старыми ресурсами. Локальная проверка геометрии не заменяет этот прогон; прирост FPS не измерялся.


Старый отдельный плагин расстановки рекламных моделей опубликован в [CS16Plugins / In-Game Ads](https://github.com/F4ntik/CS16Plugins/tree/master/ultrahc/in_game_ads): там свои исправления перемещения и сохранения, инструкция и тестовый ZIP. Для новой таблички SpriteLetters его устанавливать не требуется.
