# SpriteLetters 1.4.1-mdl-dev — составная объёмная рамка

Локальная экспериментальная сборка от 8 октября 2026. Четыре плагина и четыре MDL собраны; работа в игровом клиенте ещё не проверена. Действующий сервер не изменялся.

## Что получилось

В редактор добавлено оформление «Объёмная MDL (пробная)». Рамка и фон принадлежат надписи: меняются и сохраняются вместе с ней. Три прежних спрайтовых оформления также доступны.

«Плашки» в спрайтовом варианте — плоские прямоугольные секции фона и окантовки. В MDL-варианте это настоящие объёмные детали: фон, наклонные планки и четыре угла. Прежние исходные модели не менялись. Новые SMD/QC созданы программно для аналогичной составной конструкции; это не автоматическое разрезание исходного markee_banner.mdl.

- Размер: ширина 32–512, высота 16–128 игровых единиц, шаг 4.
- MDL: окантовка шириной 4 единицы, общая толщина 3. Фон имеет толщину 1.
- Каждая секция имеет заранее скомпилированный размер; при изменении рамки плагин выбирает нужные секции и переставляет их.
- Размер 256 × 64: 35 деталей MDL либо 34 спрайта, плюс объекты букв. Четыре файла MDL содержат 99 вариантов деталей, а не создают 99 объектов на табличку.
- Для всех 3509 допустимых размеров MDL максимум — 48 деталей. Код ограничивает рамку 64 деталями, число рамок — 32 и сохраняет запас 64 свободных объектов карты. Реальное доступное число зависит от карты и других плагинов.

## Как попробовать

Используйте отдельный игровой стенд с совместимыми AMX Mod X, ReAPI и JSON-модулем. Сборка выполнена компилятором AMXX 1.10.0.5461.

1. Сохраните копию каталога addons/amxmodx/configs/plugins/SpriteLetters/Saves.
2. Из архива перенесите addons, sprites и models в cstrike стенда. Не заменяйте пользовательские сохранения; в архиве их нет.
3. Установите комплект плагинов в порядке SprLetters.amxx → SprLett-Saver.amxx → SprLett-Editor.amxx → SprLett-Gradient.amxx. Уберите дубли старых версий из списка загрузки.
4. Все четыре models/SprLett/panel_*.mdl и sprites/SprLett/panel.spr должны быть доступны клиенту; при FastDL добавьте их и туда. Перезапустите карту для загрузки ресурсов.
5. Выберите надпись в slmainmenu, поставьте её на поверхность командой slplace. В меню рамки выберите «Объёмная MDL (пробная)» либо выполните в консоли:

    slpanel 256 64 3

Третий аргумент: 0 — спрайт графит, 1 — синий, 2 — бронза, 3 — MDL. Без третьего аргумента сохраняется выбранное оформление. slpanel 0 64 убирает рамку. slsave явно сохраняет надпись и рамку.

Если хотя бы одного MDL нет, объёмное оформление не включается; причина отсутствующего файла пишется в журнал. Плоские рамки используют отдельный panel.spr.

## Сохранения и возврат к прежней версии

Версия читает старые надписи без рамок и спрайтовые рамки 1.4.0-dev. MDL сохраняется с PanelStyle = 3. Проверка в 1.4.0-dev такое значение не принимает: перед возвратом восстановите копию сохранений либо в новой версии переключите все MDL-рамки на спрайты и сохраните их. Не смешивайте core, saver и editor разных сборок.

## Проверки

- Четыре AMXX собраны без ошибок и предупреждений.
- Четыре MDL: IDST v10, корректные размеры файлов и границы геометрии, варианты деталей соответствуют исходникам.
- Три автоматические проверки пройдены: все 3509 размеров без дыр и пересечений в плоскости; замкнутая геометрия и направление поверхностей всех деталей; отказ при обрезанном MDL.
- Независимый статический просмотр связки генератора, выбора деталей, меню и сохранения: блокеров не найдено.
- Изображения построены из настоящих ресурсов, для MDL — из геометрии скомпилированных файлов. Это не игровые скриншоты; освещение условное.

До использования на основном сервере остаётся проверить в CS 1.6: ориентацию на стене/полу/потолке, вид с обратной стороны, переключение sprite ↔ MDL, несколько минут изменения размера и перемещения без роста числа объектов, slsave → смена карты → восстановление.

## Исходники и воспроизведение

Полная рабочая структура находится в source/ModularFrame; журналы — в outputs. MANIFEST.sha256 содержит хеши файлов архива.

Генератор tools/build_model_parts.py требует Python 3 и стандартную библиотеку. Он создаёт model-source/*.smd, *.qc и текстуры. Компилировать каждый panel_*.qc нужно из model-source; готовые модели попадут в ../assets/models/SprLett. Использованный компилятор и его SHA-256 описаны в docs/compiler-provenance.md; исполняемый файл компилятора в архив не включён.

Проверка: python -m unittest discover -s tests -v из source/ModularFrame. Просмотрщик preview_mdl.py дополнительно использует установленные Pillow и NumPy; preview_sprite.py — Pillow. Для повторного создания иллюстраций сначала запустите inspect_models.py и preview_sprite.py, затем preview_mdl.py. Иллюстрации используют Arial из Windows.

Сведения о прежних исправлениях редактора и сохранения: docs/REVIEW-base-1.4.0.md. Исправление In-Game Ads остаётся отдельным пакетом; этот архив расширяет SpriteLetters.
